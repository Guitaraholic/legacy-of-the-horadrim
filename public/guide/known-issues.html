Report a bug

Use the report tool that came with your build

Windows

HoradrimLegacy report a problem

Double-click it on your Desktop.

Steam Deck or Linux

bash "<D2R>/mods/HoradrimLegacy-crash/d2r-crash.sh"

In Desktop Mode, paste it into Konsole. Replace <D2R> with your Diablo II: Resurrected folder.

Use it for any bug. After a crash, run it before restarting the game. If the game froze, say so: a freeze may leave no crash details.

Find the scripts or capture a Windows freeze

In your Diablo II: Resurrected folder, open mods/HoradrimLegacy-crash, right-click d2r-crash.ps1 and choose Run with PowerShell. Installed by hand? The scripts are directly in mods: mods/d2r-crash.ps1 or mods/d2r-crash.sh.

Windows freeze capture: select 7, Freeze (watch) before repeated runs, or while D2R is frozen. Leave the game and PowerShell open. After 30 seconds without a D2R window response, it saves a local minidump and available session logs. CurrentPreset is included only if the logs contain it.

The watcher needs 64-bit Windows PowerShell and the same privileges as D2R. It cannot capture a whole-PC lockup or a freeze where the window still responds. See REPORTING.txt beside the scripts for the full steps. Capture collects evidence; each game freeze still needs a retest.

What it sends, and if sending fails

It asks the problem type and what happened, shows you the text, and sends it only when you agree. The tool sends text, not files or character saves. Freeze minidumps, raw logs and the report copy stay in the printed local folder. Minidumps contain game memory: ask the maintainer how to transfer them privately. The service accepts text only. A freeze is reported under Performance. If sending fails, it keeps your answers and prints a retry command. Save the receipt link it prints to check your report's status. Receipt links expire after 90 days.

Screenshots or a visual bug?

Missing textures, broken scenery or a tooltip that looks wrong: post it on Discord with screenshots. For a map, include the game view and minimap.

Known problems in this release

No known problems are listed for this release. If something goes wrong, report it.

What's wrong?

The game starts, but without Legacy of the Horadrim
  1. Check the folder: the path must be mods/HoradrimLegacy/HoradrimLegacy.mpq inside your Diablo II: Resurrected folder. Create mods if it isn't there.
  2. Check the launch options. Steam: open Properties and set launch options to %command% -mod HoradrimLegacy -txt -resetofflinemaps. Battle.net: Game Settings, then Additional command line arguments -mod HoradrimLegacy -txt -resetofflinemaps.
  3. Play an offline character: the mod works only offline.

The four install steps are on Install.

"Data version mismatch detected" when the game starts

The game shows this when the mod does not say which game version it was made for, or names a different version than yours.

  • No detected version number: release 0.1.0 left out this record. Choose Exit, then install the newest release: delete the old mods/HoradrimLegacy folder and put in the HoradrimLegacy folder from the new zip.
  • Two different numbers: Blizzard has patched the game since this release. Check for a newer release. If there is none yet, Continue starts the game, but some text or data may be wrong: report the bug with both numbers from the message.
Text looks wrong after an update

Leftover files from an older build can break the game's text. Delete the old mods/HoradrimLegacy folder, then put in the HoradrimLegacy folder from the new zip. It should hold only HoradrimLegacy.mpq.

The game crashed

Run the report tool before you restart the game. If the game froze, say that it froze: a freeze may leave no crash details.

Where are my characters?

Your LotH characters are kept apart from your vanilla characters and carry over between updates. On Windows: Saved Games/Diablo II Resurrected/mods/HoradrimLegacy.

How do I update?

Replace the mods/HoradrimLegacy folder with the HoradrimLegacy folder from the new release's zip. Your characters are stored elsewhere and stay. If you still have the old 10×8 inventory, empty row 8 first.

How do I uninstall without losing items?
  • Empty inventory columns 11–12 and rows 5–7 on every character.
  • Empty stash columns 11–13 and rows 11–12.
  • Take off every mercenary's rings, amulet, belt, gloves and boots.

Items that exist only in Legacy of the Horadrim, such as its uniques, sets, reagents and fragments, are lost either way.

I played a test build: does my character carry over?

Test builds and public releases use separate mods and save folders. Test characters stay in their original folder; start a new character for the public release.

Can I play with a controller?

Connect a controller before launch; D2R switches layouts automatically. The expanded inventory and mercenary slots support controllers.

The graphics look old (the G key)

Press G to switch back to the HD graphics. Legacy of the Horadrim doesn't support the legacy graphics.

Does it touch Battle.net or my online characters?

The mod works offline, changes game data only and never touches Battle.net or online characters.

Testing
What do I need to try the mod?

You need Diablo II: Resurrected with Reign of the Warlock (patch 3.3), on Windows, Steam Deck or Linux. Use an offline character. Install and launch options.

What can I try, and what feedback helps?

Play the campaign from Normal through Hell, then the Sanctuary Stones and the Descent after Baal. New and existing offline Reign of the Warlock characters work; modded saves stay in a separate folder.

  • Level a new character and try the leveling uniques in Normal and Nightmare.
  • Tell us how often you meet a Gilded Fallen, the gold Fallen that flees and drops loot.
  • Try the reworked skills. Skill levels cap at 25.
  • Try the 191 new runewords, nine two-piece sets, unique charms and jewels.
  • Collect Horadric reagents and Stone Fragments from act bosses and named monsters. They stack in the stash's Materials tab.
  • Gamble grimoires and daggers at Gheed. Akara sells a Token of Absolution for 100,000 gold for a full respec.
How do I get a new map each game?

Use the launch options from Install step 2, which include -resetofflinemaps: -mod HoradrimLegacy -txt -resetofflinemaps. For Steam, use %command% -mod HoradrimLegacy -txt -resetofflinemaps. This also clears the explored automap each game. Without it, an offline character keeps the same map until you switch difficulty.

How do I report something I find?

Check the known problems above, then start with the report tool. Use Discord with screenshots for visual bugs. If you do not have the script or prefer not to run it, Discord and the website form are available in the reporting section.
