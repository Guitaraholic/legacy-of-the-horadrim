# 0.0.2931 — Crash fixes first

Pre-release (private alpha) · Compared with 0.0.2918.

## Other fixes

- Every added map now uses the setting that fixed the Menagerie of Fahir crash, so eight more maps should stop crashing at their edges.

- A crash report now sends only the crash file from that crash, never an older one.

- In the Moonwood, you can walk right up to the water on both river banks.

- On the Bastion Walls&#x27; east edge, you now stop at the top of the cliff.
