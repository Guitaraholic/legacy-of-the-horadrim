# 0.0.3222 — Oils as essences

Each Sentinel oil now works as an essence with its own recipe card, and the Crypt of the Vigil ships with plain packs.

Pre-release (private alpha) · Compared with 0.0.3198.

## New

- Each Sentinel oil is now an essence. Its tooltip is a recipe card: the gem lines show which stat each Perfect Gem gives on each item type.

## Other fixes

- The Crypt of the Vigil no longer crashes after the second Sentinel shade.
