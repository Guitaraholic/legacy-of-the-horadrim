# 0.0.2429 — A prize in the Vault

The Horadric Vault gains a new creature carrying a unique or set prize.

Pre-release (private alpha) · Compared with 0.0.2411.

## New

- The Gilded Wretch joins the Horadric Vault and drops one prize from a pool of 840 unique and set items.

## Other fixes

- Item source pages now include the Gilded Wretch for every eligible prize, including items with extra drop modifiers.
