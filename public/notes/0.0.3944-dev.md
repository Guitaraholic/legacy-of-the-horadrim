# 0.0.3944 — Patch notes and news, rebuilt

The wiki&#x27;s patch notes and news pages get their new layout, with every item, skill and boss linked, ready for 0.1.0. No game data changes.

Pre-release (private alpha) · Compared with 0.0.3932.

## New

- Patch notes now have a contents column with each section&#x27;s count and a count per class, section headings with art and a guide link, and a skill icon beside each skill change.
